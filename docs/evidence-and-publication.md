# 证据索引与公开范围

这是设备所有者授权公开的案例文档。公开内容从私有证据中逐项提取事实并重写，没有整体复制原始日志、工作目录或参考项目。参考项目的源码、公开恢复候选和合成测试未重新分发。

## 证据层级

[evidence-index.json](../evidence/evidence-index.json)把文档中的 E01–E20 对应到证据类型及保留的检查结果。[case-summary.json](../evidence/case-summary.json)保存带时间的统计口径及机器可读摘要。后续新增原始记录仍只保留在私有目录。

三段关键内存切片的 SHA-256、来源文件及文件内偏移公开，原始切片不公开。摘要用于所有者将来持有原件时核对；没有二进制原件的第三方不能仅靠摘要独立验证内容。仓库因而是一份有明确证据定位的公开报告，不是完整可复现的取证镜像。

部分事实只依赖受影响主机的日志和时间戳，未与独立流量证据或可信时间源互证。内存来自运行系统的顺序采集，可能有重复、残片和不同时间的内容。进程名、PID、字符串邻近和命令调用各自都有边界，报告未把它们单独当作完整执行链。

新增 S1 关联同时参考既有中继连接日志与内存内容；仍没有完整利用请求。新增进程关联通过句柄、交换槽、页表、mm 与任务对象逐级核对，而没有只凭出现同号 PID 作判断。新取得的解压表示也与原始 RAM/逻辑交换副本去重，已修正重复页覆盖表述。

## 脱敏规则

公开版使用 NAS-A 表示设备，没有公开远程入口、端口、真实公网/内网地址、设备登录名、口令、FRP 凭据、个人共享目录或原始文件名。GitHub 所有者身份随仓库公开，不与 NAS 登录身份关联披露。

新关联的外部节点使用 S1 标识。第三方收录页面单独列为外部引用，不把网站转述当作对未公开原始证据的独立复核。

没有上传完整内存、交换数据、原始认证日志、私钥或候选密钥、业务文件、勒索信中的个人访问标识、支付信息或对话记录。已知脚本只公开用于比对的文件摘要及行为说明，没有上传脚本本体或完整利用载荷。

公开的系统路径、漏洞特征和内存文件名用于理解事件；它们不包含远程连接凭据。Git 忽略规则只是辅助，实际发布从独立目录的明确文件清单进行，原始证据从未加入本仓库历史。

## 更新规则

数量变化应新增带时间的检查点，保留旧统计的范围。只有取得有效密钥并通过本机样本验证后，才更新“尚未找到密钥”的结论；只有取得来源证据并建立时间关联后，才更新入口 IP 判断。新的猜测不覆盖旧证据，目录重排也不视为内容修复。

本版记录后期在原 NAS 上写入恢复新目录的事实，没有把在线卷描述为离线副本，也没有声称完成全盘镜像或全面清除恶意软件。
