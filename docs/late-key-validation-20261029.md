## 换出页边界、格式、TAR 和 SSE 保存区

新增 **23,480** 个跨页序列，其中 **130** 个跨页表边界；每个输出均独立核对。边界候选导出 527,432 个 AES 值，新增五组 SSE 保存区导出 73,472 个值，该轮并集 **600,903**，全部文件尾验证未命中。未完成跨 PMD 或大页的一般重建。

另外一轮对 MCA、SQLite、JSON、C/Java/XML 源码添加 7,442 个前缀假设，测试 42,245,424 个材料尝试；298 个短前缀提示均未通过结构检查。地图假设依赖开头区块位置为空等条件，文本前缀也只是待验证假设；这组与其他格式测试重叠，不相加。

另一组已完成结果针对 5,358 个文件构造 39,946 个格式前缀特征，另检查 126 个 TAR 文件头。TAR 的 `ustar` 标记按文件偏移 257 处理，测试相应 ChaCha 块 4、必要时块 5，并以完整头部 checksum 复核。格式与 TAR 各扫描 205,981,775 个已有记录尝试，无有效文件头。

另检查 2/4/8/16 路 SIMD ChaCha 交织和 2/4/8 路 AES 轮密钥复制。J1900 的本机特征指向 SSE/FXSAVE，不支持 AVX/XSAVE；801 个保存区形状得到 588 组不同寄存器材料，但没有归属到加密进程的证明。从中生成 7,183,008 次 AES 假设，去重后新增 **5,554,458** 个值，对全部文件尾进行 **133,973,526,960** 次筛选，0 命中。该组材料与此前 326,875 个值的并集是 5,881,333，仅限那组结果的口径。

ChaCha 完整及轮中寄存器逆推也没有有效结构。FXSAVE 只覆盖保存的 SSE 状态，不能当作已经重建一般 CPU 寄存器或曾退出的加密进程。
